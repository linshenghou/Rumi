# README visuals

The README uses the existing Rumi app icon directly from `macos/Resources/Branding/RumiIcon.png`.

`translate-action.png` is the unmodified action close-up supplied by the maintainer. It appears beside the translation feature, at a small size. It contains no credentials or private paper content. It is not evidence of installation acceptance.

The English and Chinese pages use GitHub-supported HTML for a centered identity block and a compact two-column feature overview. Badge text reports platform, license and the actual beta-in-preparation state; it does not claim a published release or installation acceptance.

Structure references: [Jan](https://github.com/janhq/jan) for a clear product description and grouped entry points, [Cherry Studio](https://github.com/CherryHQ/cherry-studio) for app identity and feature sections. No wording, screenshots or branding from those projects is reused.

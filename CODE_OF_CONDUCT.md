# Community code of conduct

Rumi welcomes people of all backgrounds, experience levels and languages. Be respectful, assume good intent, give specific constructive feedback, and respect privacy and copyright.

Harassment, threats, discriminatory language, sexual harassment, publishing private information, and sustained personal attacks are not acceptable. These standards apply in issues, pull requests and other Rumi community spaces.

Maintainers may edit or remove harmful content, lock discussions, or restrict participation. Responses should be proportionate: clarification or a warning for minor incidents, temporary or permanent exclusion for serious or repeated harm. Maintainers are held to the same standards.

Report public conduct problems through GitHub's “Report content” tools. If a report involves a security vulnerability, use the private security route in [SECURITY.md](SECURITY.md). Do not publish personal information or sensitive evidence in a public issue. GitHub platform reports can also be used when the concern involves a maintainer.
